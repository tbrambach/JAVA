# Java-Projekte

Jedes Unterverzeichnis ist ein eigenes IntelliJ-Projekt. Öffne in IntelliJ
nicht das übergeordnete Verzeichnis, sondern den gewünschten Projektordner,
zum Beispiel `ifef10`.

## Neues Projekt anlegen

1. Einen neuen Ordner mit dem Projektnamen erstellen.
2. Java-Dateien unter `src/main/java/` ablegen.
3. Den Projektordner in IntelliJ über `File | Open...` öffnen.
